 # PBMC scRNA-seq Analysis Project
 
  ## Project Title
  Cell Types Beyond Lymphocytes: Multi-Sample scRNA-seq Analysis of Human PBMCs in R 
  
  ## Interns
  Maria and Eylul
   
  ## Dataset Source
  Public 10x Genomics datset: 20k Human PBMCs Multiplex Sample, Donors 1-4.
  The raw ".h5" files should be downloaded from the official 10x Genomics dataset page and placed into the "data/"
  folder.
  
  ## How to Reproduce
  1. Clone the repository.
  2. Open the R project in RStudio("renv" will automatically handle package dependencies).
  3. Run the scripts in the "scripts/" directory or render the Quarto/R Markdown report.
